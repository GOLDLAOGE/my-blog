# 前台可维护区域与后台配置集成

状态：范围已获用户确认；本文待用户审阅，尚未进入实现。

## 目标与边界

用户能够在后台按前台区域找到对应设置，提交后更新预览分支，等待 Cloudflare 构建完成，在前台看到对应变化。保留原主题视觉、当前蓝白后台样式、现有文章和未开放配置。

只在 `feature/cms-backend` 实现和验收；不合并 main，不调整生产环境或密钥。GitHub 提交成功不等于部署成功；不承诺无需构建的即时生效。

不做任意 YAML 编辑、代码注入编辑器、CDN/构建内部参数面板、主题切换、第三方账号配置。统计、评论、支付、音乐、相册等未启用服务不属于本次。已有自定义字段必须保留，不擅自替换作者信息和主题示例文案。

## 现状与关键缺口

现有后台开放 7 个站点字段、26 个主题字段，以及菜单、导航分组、社交链接。设置接口从同一 Git 提交读取两份 YAML，并用 head 校验与原子提交防止覆盖。

实际预览首页仍包含主题默认分类入口、人物动画与推广横幅。侧栏存在作者卡片、微信卡片、标签、归档和运行时间，当前后台不能完整维护。独立页面尚无后台编辑入口。

模板证据：`layout/includes/top/top.pug`、`widget/card_author.pug`、`widget/card_weixin.pug`、`widget/card_webinfo.pug`、`footer.pug` 和 `page.pug`，均在 `themes/anzhiyu/` 下。

## 后台交互

标量使用文本框、数值框、颜色输入、枚举选择及开关；结构化列表提供增删和顺序调整，不使用 JSON/YAML 输入。图片复用现有 R2 上传。图标继续采用主题图标类名，附示例，不能把图标名称解释成图片地址。

显示条件必须写明：人物动画开启时首页文案不显示；首页顶部区域关闭时其子配置不展示在前台；侧栏总开关影响卡片；侧栏运行时间与页脚运行时间分别管理；默认明暗模式可能被访问者已保存的偏好覆盖。

现有表单一次保存全部分类保持不变。保存按钮明确提示提交到预览分支，成功状态显示 commit SHA 和“等待构建”，提供查看前台链接。不新增需要 Cloudflare 凭据的部署轮询服务。

页面管理列出已有普通页面，排除 admin、文章、媒体和基础设施文件；允许新建安全 slug 的普通内容页。关于页默认使用普通 Markdown 布局，不构造原作者复杂 about.yml 数据卡片。友链页使用主题原生 `type: link` 与 link.yml，能编辑分类名称/说明及站点名称/描述/链接/头像。保留现有未开放 front matter 和友链属性。页面内容和友链数据一起保存时必须为一次原子提交。此次不提供删除页面动作。

## 数据、接口与安全

扩展现有设置白名单和类型校验，不接收任意配置路径。增加 boolean/text/image/url/list/color/enum 和有界整数所需的字段规则；枚举必须在服务端验证。颜色只接受合法十六进制；链接和图片沿用安全 URL 规则；日期校验真实可解析值。原有 HTML 字段保持拥有者可编辑语义，不新增脚本注入能力。

设置读取缺失字段应回退主题实际默认值，不能因后台展开表单而默默将原有默认值改为 false/0。结构化列表保留未开放属性，编辑、排序和新增使用显式 schema 与稳定匹配方式，不以所有任意对象键为可信路径。

页面接口复用 requireOwner、CSRF、Origin 校验和 GitHub 仓库操作。路径仅允许普通页面目录内的 index.md；禁止 admin、_posts、_data、点路径、斜线注入及任意文件读写。新增 slug 必须无冲突；更新使用快照 head，冲突返回 409，不覆盖远端文章或配置。缺少 link.yml 时按空列表读取，仅在用户提交友链时创建。

2. 后台控件与列表编辑：复用现有渲染器，保持已提交 UI 风格；完成分组覆盖、隐藏分类保值和提交结构检查。
3. 页面与友链：独立的路径白名单、序列化与接口；完成权限、路径、冲突、属性保留和原子写入测试。
4. 主题输出与预览验收：只有配置映射不能满足已承诺效果时才最小修改模板；确认文章与未知配置无变化。

具体实施步骤和命令在本文批准后另写计划。本次不先行推送功能。

## 完成判定

每组功能至少有“后台值 → 持久化字段 → 生成 HTML/CSS/资源”的验证，不能仅测试 API 返回成功：

- 首页：修改文案/分类入口/横幅，输出对应文字、href 和上传图片 URL；验证人物模式的条件关系。
- 侧栏：修改作者描述、公告和微信图片，检查输出；卡片关闭后不生成该卡片；运行日期写到真实 runtimeshow 属性。
- 文章：目录、版权许可、相关文章和元信息开关改变生成内容；文章正文、slug 与既有 SEO 无损。
- 外观/页脚：主色进入生成 CSS；明暗默认策略进入配置；底栏链接/徽标/分组/图片对应生成输出。
- 页面/友链：后台新建或修改后构建产生路由；标题、正文、SEO、分类友链和头像准确显示；不产生任意文件访问。
- 安全与保留：未登录、非拥有者、非法 URL/枚举/路径、过长输入被拒绝；并发 409；未知 YAML/front matter 属性保留。
- 回归：全量测试与 Hexo 构建通过；桌面/手机后台无横向溢出、列表与保存可用。
- 线上：在获得具体测试值与写入授权后，提交一组可识别的预览改动，核对 GitHub 提交和 Cloudflare 成功部署，再检查前台；恢复临时测试值。不得用本地生成成功冒充线上验收成功。

若线上检查需要登录或部署等待，明确记录未完成项。只有实际前台更新已核对后，才能称端到端验收完成。
