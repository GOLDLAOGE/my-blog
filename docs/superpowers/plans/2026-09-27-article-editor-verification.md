## 独立审查与修复

一次独立整分支审查，无 Critical；Important 复现后集中修复：

1. 上传期间正文变更后拒绝过期插入，避免用旧偏移覆盖新内容。
2. 内联 HTML 用内联保护标记保留句子边界。
3. 缩进、引用、列表内代码围栏不解析为 HTML/主题组件。
4. 双击重复组件保留具体出现位置；唯一组件在前文格式归一化后仍可编辑。

测试已覆盖上述回归；真实浏览器确认组件保存正常。

Minor 保留限制：Vditor 对源码输入的库专属数学/额外图表围栏仍可能请求未打包的同源运行资源；本次未增加数学、ECharts 等功能，用户应通过已提供的主题流程图组件编辑 Mermaid，其他旧特殊语法留在源码模式。未扩展第三方库全部能力。

## 实现取舍（Rulings）

- 静态 Hexo 使用同源 esbuild 资源包，Mermaid 按需加载；代价是增加构建步骤。
- npm 缓存置于 `/private/tmp`，不修改用户目录权限；代价是缓存可丢弃重建。
- 组件弹窗独立于既有发布 API 模块；代价是增加一个 UI 模块。
- 上传/弹窗捕获插入位置，并在文章或正文变更后拒绝过期回调；代价是需要重新插入。
- 适配器自管撤销历史（50 项/约 10M 字符），避免保护标记与库历史错位；代价是历史粒度及内存限制。
- 使用主题已有图片说明与 Mermaid 开关，未重写主题；既有图片 alt 将可见。
- impeccable 静态检查仅报告提示块的彩色左边框；保留该边框以对应原主题提示组件，并非通用卡片装饰，未为消除误报重设计主题。
- 审查未判范围：原生 IME/选择等由本轮浏览器边界验证、生产 R2/GitHub/Cloudflare 不作写入验收、第三方依赖全面漏洞/许可证审计及无关全站行为不扩展。没有因此宣称生产已部署成功。
