## 实施裁定与代价

1. 共用结构化列表保留行身份，供设置及友链使用；若抽象不合适，代价为内联小模块。
2. 共用列表控件和现有 jsdom 测试，不增加依赖；若拆分不合适，代价为合并文件。
3. 按 impeccable 将桌面/手机检查合并到最终完整界面；代价为视觉问题较晚发现。本次未发现溢出。
4. 共用页面提交逻辑，新增 `GET /api/pages?type=link` 加载共享友链；代价为一个小 API 辅助层。
5. 新页面检查整个 Git 树，包含平面文件及大小写冲突；代价为保守拒绝重名页面。
6. 已有页面类型不可在 UI 改动，新增友链页先读取共享数据；代价为类型迁移需另行处理。
7. 实际构建验证需要的三处主题模板/友链默认样式做最小修正；代价为后续升级主题需要保留补丁。
8. 同名导航分组按来源身份分开保存；新增条目只能加入唯一同名组，存在多个同名组时明确拒绝；代价为用户需先给新增条目指定唯一分组名。
9. 排序问题从 Minor 提升为 Important，因为已批准列表顺序控制要求；已修正，不留待办。
