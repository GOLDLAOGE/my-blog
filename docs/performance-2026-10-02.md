# XIAX.CAFE 第二轮性能优化

用户要求：按诊断建议优化一轮，验证页面正常与手机性能变化。

基线：7e8753b；用户提供 PSI 手机 87，FCP 2.4s、LCP 3.0s、TBT 130ms、CLS 0、SI 4.8s。

计划与验收：
- [x] 使用已有 esbuild 压缩发布 CSS/JS，保留全局脚本接口和 CSS 行为；运行输出行为测试、比较 gzip 大小。
- [x] 手机导航不读取隐藏菜单尺寸；首页恢复颜色时合并读取；Firefox 标准滚动条规则不覆盖 Chrome/Safari 的现有规则。验证手机菜单、桌面 resize、深浅色和 PJAX。
- [x] 为内置封面补充真实宽高，保留已有 srcset、优先级及任意 CMS 图片行为；更新修改资源的缓存版本。
- [ ] 完整构建与测试，移动端同条件三轮对照；发布后核对线上资源并重新运行 PSI。

约束：不安装插件，不删除主题样式，不改内容/品牌/后台。暂不按页拆分 CSS，因为 PJAX 跨页需要额外加载管理，本轮先验证更小范围的收益。

基线测试：构建后 208/209 通过。test/media.test.js 的上传路径断言写死 2026/09，当前月份 2026/10 导致既有失败；不修改无关测试或媒体功能。

根因证据：PSI 渲染阻塞只有 css/index.css（79.1 KiB）；95/98 非合成动画包含 scrollbar-color；adjustMenu 在手机必定收起菜单时仍测量所有子节点；首页 coverColor 交替写 CSS 变量和 getComputedStyle。


## 本地验证

- 构建成功；修复了 Stylus 不支持 supports selector 直接语法的问题，采用原生 CSS 字面块；压缩脚本遇到空资源会失败。
- 完整测试 210/211 通过，唯一失败仍是基线媒体上传测试月份写死问题；相关新增回归先失败后通过。
- 独立只读审查：无 Critical/Important，相关 14 项测试独立通过。
- Chrome 手机菜单可打开并用 Escape 关闭；PJAX 首页进入文章、二维码按需加载正常；桌面首页、手机首页、深浅色切换正常，没有脚本错误或横向溢出。
- 内置原始封面均以 sharp metadata 验证为 1440×810；保留图片内容、srcset 与优先级。
